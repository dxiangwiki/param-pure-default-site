工具核心作用

精准判定来源

无论数值是否相同，都能准确判断参数是用户传入，还是使用默认值。

快速安装

npm install param-pure-default

基础使用示例

import ParamDefaultTrack from 'param-pure-default'

const track = new ParamDefaultTrack()

function showNum(num = track.setDefault(5)) {
    if(track.isDefault()){
        console.log('默认值：', num)
    }else{
        console.log('用户传入：', num)
    }
    track.reset()
}

showNum(10)  // 用户传入
showNum()    // 默认值
showNum(5)   // 用户传入

底层核心实现原理

1. 默认参数短路执行
用户传参 → 默认值不执行
用户不传 → 默认值自动执行

2. 函数调用留痕
使用 setDefault() 代替固定值，执行时自动标记状态。

3. 状态溯源判定
不比较数值，只看是否执行过默认逻辑。

4. 动态规划思想
只追踪“是否走默认路径”这一核心状态，剥离无关判断，极简且绝对可靠。
